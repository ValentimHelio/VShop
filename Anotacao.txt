==> EF Core Migrations : Ferramenta dotnet-ef
	-> instalar ferramenta EF Core Migration Tools
		--> dotnet tool install --global dotnet-ef
	-> atualizar ferramenta EF Core Migration Tools
		--> dotnet tool update --global dotnet-ef
	-> Uso:
		--> dotnet ef migrations add <nome-migracao>
		--> dotnet ef migrations remove
		--> dotnet ef database update

==> Usando o Duende IdentityServer - Templates e Interfaces com o Usuário
	--> Instalar os templates do IdentityServer
		--> dotnet new -- install Duende.IdentityServer.Templates
	--> Incluir a interface para Login, Logout, etc. (Razer Pager)
		--> dotnet new isui
